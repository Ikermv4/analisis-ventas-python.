# Análisis de Ventas y Simulación Estadística con Python

## Descripción del proyecto

Proyecto académico desarrollado como parte del curso **Python for Data Science**, impartido por Actuarios por México (AxM).

Su objetivo es aplicar herramientas de programación, análisis de datos y estadística para estudiar el comportamiento de las ventas y generar información útil para la interpretación de resultados comerciales.

## Herramientas utilizadas

- **Python:** programación y análisis de información.
- **pandas:** manipulación, limpieza y organización de datos.
- **NumPy:** operaciones numéricas y cálculos estadísticos.
- **Matplotlib:** visualización gráfica de resultados.
- **Jupyter Notebook:** desarrollo y documentación del análisis.

## Metodología

1. Importación y exploración de conjuntos de datos de ventas y productos.
2. Limpieza, organización y validación de información.
3. Integración de datos y cálculo de indicadores.
4. Análisis de ingresos y segmentación de ventas.
5. Elaboración de visualizaciones estadísticas.
6. Aplicación de simulaciones para estudiar el comportamiento de los ingresos.

## Competencias desarrolladas

- Análisis exploratorio de datos.
- Procesamiento de información mediante Python.
- Estadística descriptiva y simulación.
- Interpretación y visualización de resultados cuantitativos.
- Resolución estructurada de problemas.
